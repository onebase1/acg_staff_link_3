## 4. DESIGN SPECIFICATIONS

### Color Scheme (White-Labeled Per Agency)

**Dominion Healthcare:**
- Primary Color: `#2563eb` (Blue)
- Secondary Color: `#7c3aed` (Purple)
- Gradient: `linear-gradient(135deg, #2563eb 0%, #7c3aed 100%)`

**Status Colors:**
- Success/Confirmed: `#28a745` (Green)
- Warning/Pending: `#ffc107` (Yellow)
- Critical/Open: `#dc3545` (Red)
- Neutral: `#6c757d` (Gray)

### Typography
- Font Family: `-apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto`
- Headers: 24-28px, 700 weight
- Body: 14px, 400 weight
- Small: 12px, 400 weight

### Responsive Design
- Max Width: 600px (daily), 650px (weekly)
- Mobile Breakpoint: 600px
- Stack cards vertically on mobile

### Accessibility
- WCAG 2.1 AA compliant
- Alt text for all icons (emoji fallback)
- High contrast ratios
- Semantic HTML
