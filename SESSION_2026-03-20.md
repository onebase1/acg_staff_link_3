## What Was Done

### 1. Payslip Template — UK Employment Rights Act Compliant (`src/pages/Payslips.jsx`)

Complete rewrite of `handlePrintPayslip` to produce a legally compliant UK payslip:

- **Employer header**: Agency name, address (reads plain-text `address` field from `agencies` table), PAYE reference
- **8-cell info grid**: Employee, NI Number, Tax Code, NI Category, Pay Period, Payment Date, Payment Method (BACS), Total Hours
- **Earnings/deductions table**: Basic Pay row shows `@ £25.00/hr` rate pulled from `timesheets[0].hourly_rate`, PAYE and NI rows show tax code and NI category
- **Compliance band**: NI Number, NI Category, Total Hours, Shifts Worked, Tax Code (repeated for legal compliance)
- **Shift Journal**: Date | Role (abbreviated) | Client | Hours | Start | End | Rate | Pay columns — all auto-hide when data absent
- **Net pay box**: Gross − Deductions shown inline
- **Footer**: Legal income-proof wording

### 2. Payslip CSV Export — Payroll Upload Format (`src/pages/Payslips.jsx`)

Redesigned `handleExportCSV` as a two-section payroll interchange file:

- **Section 1** (one row per payslip): NI Number, DOB, Tax Code, NI Category, Sort Code, Account Number, Account Name, Period, Gross, PAYE, NI, Net, Agency PAYE Ref
- **Section 2** (one row per shift): Date, Role (abbreviated), Client, Hours, Start, End, Rate (£/hr), Shift Pay
- BOM (`\uFEFF`) for Excel compatibility
- `setAttribute('download', filename)` + `setTimeout(revokeObjectURL, 1000)` for reliable Chrome download

## Key Architecture Notes

- **Staffology** is used only for employee sync (GET/POST `/employers/{id}/employees`). Tax/NI calculations are done locally in `auto-payroll-engine` using UK 2024/25 thresholds (£1,048/month personal allowance, 20% tax, 12% NI above threshold).
- **Invoice gate**: Timesheets must have `invoice_id IS NOT NULL` before payroll can be generated.
- **Deployed function**: `auto-payroll-engine-v2` is what's deployed to Supabase. The repo folder is `auto-payroll-engine/` — these need aligning.
- **JSONB snapshot**: `payslips.timesheets` stores a snapshot of shift data at generation time. `client_name` is now included in new payslips but old ones (pre this session) won't have it.
