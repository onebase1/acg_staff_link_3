# PROJECT OVERVIEW: AUTONOMOUS AGENCY PLATFORM

## The Vision
To transform "ACG StaffLink" into a fully autonomous operation where the software manages the agency, not the humans.
**Goal:** Post-MVP, no one (Admin, Staff, Client) needs to log into a portal. All interaction happens via conversational AI (WhatsApp/Voice) and the system handles the logic.

## Naming Suggestions
The current name "Aigle Care" feels traditional. For an autonomous, AI-first platform, we need something dynamic.

### Top Recommendation: **AUTONOMA**
*   **Why:** Sounds like "Autonomous" + "Automata". It implies a self-running machine.
*   **Tagline:** "The Agency That Runs Itself."

### Connecting the Name (Functional Variations):
1.  **Autonoma Staffing** - Clear, professional, futuristic.
2.  **Autonoma Link** - Keeps the heritage of "StaffLink" but upgrades it.
3.  **Autonoma Connect** - Emphasizes the network effect.
4.  **StaffLink by Autonoma** - Good for a transition phase.

### Other Options:
1.  **AgencyOS** - The operating system for staffing.
2.  **Nexus** - The central connection point.
3.  **Operant** - Active, effective, working.
4.  **ShiftFlow** - Focus on the movement of work.
