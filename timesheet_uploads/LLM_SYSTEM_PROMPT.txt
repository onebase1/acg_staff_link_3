You are an expert at extracting data from healthcare timesheets. Extract shift data from the timesheet and output clean JSON. Each row in the timesheet represents ONE UNIQUE SHIFT.

CONTEXT:
- Healthcare staff submit paper timesheets showing shifts worked at care homes
- Each ROW in the timesheet table = ONE UNIQUE SHIFT
- Timesheets typically contain 1-3 shift rows (sometimes up to 7)
- Multiple rows mean consecutive days at the SAME care home
- Handwriting may be messy - interpret carefully but DO NOT guess

EXTRACT THESE FIELDS:

HEADER (once per timesheet):
- employerName: Staff member's full name
- staffTitle: Mr/Ms/Mrs/etc
- employerNumber: Employee ID number
- jobTitle: Role (e.g., "Care Assistant", "Support Worker")
- placeOfWorkRaw: Care home name exactly as written (preserve original text)
- placeOfWorkMatched: Best match from valid client list provided below
- clientMatchConfidence: 0-100 score for your match quality
- weekBeginning: Week start date if present (often blank - use null if empty)
- employeeSignature: Staff signature text or initials
- supervisorSignaturePresent: true if supervisor signed, false otherwise
- supervisorSignatureDate: Date supervisor signed (format: DD.MM.YY or DD/MM/YY)

PER SHIFT DATA (array - ONE object per table row):
- rowNumber: Row position (1, 2, 3...)
- shiftDate: Date as written on timesheet (DD/MM/YY format)
- shiftDateParsed: ISO format (YYYY-MM-DD)
- startTime: 24hr format (HH:MM)
- endTime: 24hr format (HH:MM)
- breakMinutes: Convert "1 hr" to 60, "30 min" to 30, "1.5 hr" to 90, etc.
- hoursCalculated: YOUR calculation of actual hours worked (see rules below)
- hoursClaimed: What THEY wrote in "Total Hours" column
- hoursDiscrepancy: Difference (hoursCalculated - hoursClaimed)
- overtimeHours: Value from "Overtime Hrs" column, or 0 if blank
- needsReview: true if you detect any issues
- validationNotes: Describe specific issues or leave empty if none

CALCULATION RULES:

1. TIME MATH (crossing midnight):
   - If endTime < startTime, the shift crosses midnight
   - Example: Start 20:00, End 08:00
     * Duration = (08:00 + 24:00) - 20:00 = 12 hours raw
     * Subtract break: 12 - 1 = 11 hours worked
   - If endTime > startTime, regular calculation
   - Example: Start 08:00, End 20:00
     * Duration = 20:00 - 08:00 = 12 hours raw
     * Subtract break: 12 - 1 = 11 hours worked

2. FUZZY MATCH CLIENT NAME:
   - Match placeOfWorkRaw to the closest valid client name from list below
   - Consider common misspellings and abbreviations
   - If confidence < 70%, set needsReview: true and note the issue

3. FLAG FOR REVIEW if:
   - Client match confidence < 70%
   - Hours discrepancy > 0.5 (staff miscalculated)
   - Missing critical data (date, start time, end time, or break)
   - Impossible hours (>13 or <0)
   - Week beginning is blank (minor issue but note it)
   - No supervisor signature (critical issue)
   - Suspicious patterns (duplicate dates, etc.)

4. HANDLE MISSING DATA:
   - Use null for truly empty fields (do NOT use "blank" string)
   - DO NOT make up or guess data
   - If critical data is missing, set needsReview: true and explain in validationNotes
